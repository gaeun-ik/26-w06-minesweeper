# 💣 지뢰찾기

Vanilla JavaScript로 만든 브라우저용 클래식 지뢰찾기 게임입니다. HTML, CSS, JavaScript 파일을 분리해 구성했습니다.

## 게임 소개

지뢰가 있는 칸을 피하면서 안전한 칸을 모두 열어보세요. 숫자는 주변 8칸에 있는 지뢰의 수를 알려줍니다. 빈 칸을 열면 인접한 빈 칸과 숫자 칸이 자동으로 펼쳐집니다.

마우스 왼쪽 버튼으로 칸을 열고, 오른쪽 버튼으로 칸의 표시를 `덮임 → 깃발 → 물음표 → 덮임` 순서로 바꿀 수 있습니다. 깃발을 세운 칸은 열리지 않습니다. 지뢰가 아닌 칸을 모두 열면 승리하고, 지뢰를 열면 게임이 끝납니다.

## 난이도

| 난이도 | 보드 크기 | 지뢰 수 |
| --- | ---: | ---: |
| 초급 | 9 × 9 | 10개 |
| 중급 | 16 × 16 | 40개 |
| 상급 | 16 × 30 | 99개 |

첫 칸을 열 때 해당 칸과 주변 8칸에는 지뢰가 배치되지 않습니다. 타이머는 첫 칸을 연 순간 시작해 최대 999초까지 올라가며, 남은 지뢰 수는 설치한 깃발 수에 따라 음수로도 표시될 수 있습니다.

## 실행 방법

저장소를 내려받은 뒤 `index.html`을 브라우저에서 열면 바로 플레이할 수 있습니다. 별도의 패키지 설치나 빌드 과정은 필요하지 않습니다.

## 커스터마이징한 부분

- 초급·중급·상급 난이도 선택과 난이도별 보드 크기 및 지뢰 수
- 난이도를 유지하는 다시하기 버튼
- 화살표 모양의 다시하기 아이콘과 클래식 지뢰찾기를 떠올리게 하는 회색 입체 타일 및 빨간 숫자 표시창
- 브라우저 너비에 맞춘 레이아웃과 좁은 화면에서의 보드 가로 스크롤
- 첫 클릭 안전, 빈 칸 자동 확장, 깃발·물음표 표시, 승리·패배 상태와 타이머

온라인 순위표, 백엔드 연동, 사용자 지정 난이도와 효과음은 포함하지 않았습니다. 제작 과정은 [guide.md](./guide.md)에서 확인할 수 있습니다.
